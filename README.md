# Utgardnet Puzzles — four games on branch001

The original [Triangle Peg](https://github.com/Halfe85/TrianglePeg/tree/main) application is expanding into a **four-game single-player puzzle collection**. This work is isolated on `branch001`; the live GitHub Pages site continues to deploy only from `main`.

## Games

| Game | Easy | Medium | Hard | Extreme | Goal |
| --- | --- | --- | --- | --- | --- |
| Triangle Peg | 15 holes | 21 holes | 28 holes | 36 holes | Jump over pegs until one remains |
| Lights Out | 3×3 | 4×4 | 5×5 | 6×6 | Switch off every light |
| 15 Puzzle | 3×3 | 4×4 | 5×5 | 6×6 | Slide the numbered tiles into order |
| F1 Start Lights | Reaction Start | 10 Seconds Perfect | — | — | React to lights-out or stop a hidden clock at 10.000 seconds |

**Triangle Peg:** preserved from `main`, including the rule-tested 7-row opening restrictions.

**Lights Out:** pressing a square flips that light and its orthogonal neighbors. The generator starts with an empty board and scrambles it by applying legal switches, so every generated position is solvable. Difficulty also increases the number of scramble presses. Pressing all the generated switches again (in any order) always solves the puzzle.

**15 Puzzle:** a grid of numbered tiles with one empty space. Only an immediately adjacent tile may move. Every puzzle is generated by scrambling the solved board with a sequence of legal moves, so there are no impossible tile permutations. Harder difficulties use larger grids and longer scrambles.

**F1 Start Lights:** two modes are available in its New Game dialog:
- **Reaction Start:** five pairs of red lights illuminate one pair per second. Once all are lit, they go out after a randomized extra 0.2–3 second hold. Tap the reaction button as soon as they go out; pressing earlier is a false start and does not set a record. Best score is the fastest valid reaction time.
- **10 Seconds Perfect:** start the stopwatch and press Stop as close to exactly 10.000 seconds as possible. The running clock hides after 3 seconds. Best score is the smallest absolute timing error (early or late).

The F1 modes measure elapsed time using `performance.now()`, not accumulated timer ticks. Results are displayed to three decimal places; mobile browser rendering and input latency mean these are entertainment timings, not FIA-certified reaction measurements. The round is cancelled when its tab becomes hidden.

All four games have separate gameplay states, independent saved best scores and no hints. The three logic games support Undo and Redo; F1 uses repeatable standalone timed attempts. Triangle Peg keeps its existing legacy score migration.

## Interface

- **Home:** choose Triangle Peg, Lights Out, 15 Puzzle or F1 Start Lights.
- **Top bar:** click the logo or Games to return Home. New Game selects difficulty in logic games or the challenge mode in F1. Undo / Redo are for logic games only.
- **Content:** responsive board and concise feedback, fitted to the viewport.
- **Bottom bar:** peg/light/tile statistics for logic games, or result / attempts / best time for F1.
- **New Game:** changing settings is confirmed only by **Start game**. Closing the modal preserves the current state.

The site uses Angular, TypeScript, and CSS. There is no server, account, shared database, or AI inference requirement.

## Development / testing branch

```sh
git clone https://github.com/Halfe85/TrianglePeg.git
cd TrianglePeg
git switch branch001
npm install
npm test
npm start
```

Open the URL reported by Angular, generally `http://localhost:4200`.

To produce the static GitHub Pages build:

```sh
npm run build -- --base-href /TrianglePeg/
```

Pure game engines live in:
- `src/app/peg-engine.ts`
- `src/app/lights-engine.ts`
- `src/app/sliding-engine.ts`
- `src/app/f1-engine.ts`

Node's built-in test runner verifies legal moves, solvability, reproducible generation, F1 false starts, randomized light holds and ten-second scoring. The `.github/workflows/branch001-check.yml` action tests and builds `branch001`, and provides the built files as a downloadable artifact. It **does not deploy over the live GitHub Pages site**.

The existing `.github/workflows/deploy.yml` remains scoped to `main`. Once this branch has been reviewed and merged, that workflow can deploy the collection to https://halfe85.github.io/TrianglePeg/.
